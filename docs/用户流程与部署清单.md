# 用户使用流程与部署清单

> 配套 [设计文档](设计文档.md)：本篇回答两个问题——**用户从装机到日常使用的完整流程长什么样**、**要搭建哪些应用 / 使用哪些服务**。

---

## 1. 全景图：一台设备 + 一个云存储桶，零自建服务器

```
你的电脑（跑 DSH 的地方）                     云（不可信，只存密文）
┌────────────────────────────────┐
│ 浏览器 GUI ── DSH Web 界面       │           ┌──────────────────┐
│   ├─ 解锁对话框（主密码）        │           │ 对象存储/WebDAV/  │
│   ├─ 保险库浏览页（仅元数据）    │           │ 私有 git 仓库     │
│   └─ 到期提醒卡片               │           │                  │
│ DSH 进程                        │  TLS      │ secrets/*.age    │
│   ├─ host 插件（工具/审计/巡检） │ ────────▶ │ meta/*.age(可选) │
│   ├─ skill（agent 行为铁律）     │  仅密文   │ sync-manifest    │
│   └─ helper CLI（唯一碰明文处）  │           └──────────────────┘
│ ~/.config/dsh-vault/（沙箱外）   │
│   私钥 · 密文库 · 审计日志       │           离线：手抄恢复码（Shamir 分片）
└────────────────────────────────┘
```

关键点：**云端没有任何服务端代码、没有常驻进程、不开放端口**——它只是一个存加密 blob 的目录。所有"应用"都跑在你自己的设备上。

## 2. 完整用户流程（按时间线）

### 阶段 0 · 一次性初始化（约 5 分钟，只做一次）

| 步骤 | 用户做什么 | 系统做什么 |
|---|---|---|
| 0.1 | 安装 dsh-vault 插件包（含 CLI + host 插件 + skill；GUI 部分随 DSH Web 加载） | — |
| 0.2 | 在对话框说"初始化保险库"，或在终端跑 `dsh-vault init` | 生成 age 密钥对；创建 `~/.config/dsh-vault/`（0700） |
| 0.3 | **设置主密码**：GUI 弹出解锁/设置对话框输入（或终端 tty 输入）| Argon2id 派生密钥 → 包裹私钥落盘。**主密码不存储、不经过模型** |
| 0.4 | 设置 2~3 个**密保问题**及答案（GUI 表单或对话） | 答案逐条 Argon2id 加盐哈希入库 |
| 0.5 | （引导完成）**备份**：屏幕显示恢复码 `XXXXX-XXXXX-…` | Shamir 3 分片阈值 2：本地片 + 云端片（主密码包裹）+ 手抄片；用户抄纸保存 |
| 0.6 | （可选）配置云存储：填 WebDAV/S3 端点与访问凭据 | `sync push` 上传初始 manifest；此后自动同步 |
| 0.7 | （可选）配置 IM 白名单、是否启用紧急销毁暗码 | 写入配置 |

### 阶段 1 · 登记秘密（四条路径，按安全性排序）

**路径 D · 本地生成（最安全，推荐用于新密钥）** —— 明文从不存在于任何聊天通道

```
你:   给 GitHub 生成一个强 token 密码，登记上，有效期一年
DSH:  已生成并入库 ✅ GitHub / 强度:strong · 到期 2027-11-02
      新密码已复制到剪贴板（60s 自清），请现在去 GitHub 完成设置。
```

**路径 C · GUI 表单（存量密钥录入，全程不经模型）**

```
你:   打开 GUI「保险库」页 → 点「新增条目」
      填：系统=阿里云 / 账号=main / 类型=api_key / 有效期 / 秘密本体
      点提交 → 直连 host 服务加密入库，对话流里什么都没有
```

**路径 B · 聊天 / IM 录入（便捷，明文过一次模型上下文）**

```
你:   记一下：GitHub token 是 ghp_xxxxxxxx...（示例），2026 年底过期
DSH:  已登记 ✅ GitHub / ghp_****c3d4 · 到期 2026-12-31 · 录入 2026-11-01 12:03
      ⚠ 聊天录入的原文会留在会话日志，已提供打码；建议高价值密钥改用表单或本地生成。
      （host 收到即加密；回执永不复述明文；可执行 vault scrub 打码原消息）
```

**路径 A · 文件移交（长私钥 / 证书文件）**

```
你:   把 ./tmp/id_ed25519 登记为 SSH 私钥，然后安全删除
DSH:  已登记 ✅ ssh / 指纹 SHA256:9fKq... · 源文件已覆写删除
      （helper 直读文件内容，agent 不读、不打印，明文不进上下文）
```

每条登记都会记录：**用在哪个系统（system/url）、账号、类型、别名标签、有效期、录入时间、来源通道**——元数据明文可检索，秘密本体只以 age 密文存在。

### 阶段 2 · 日常调取与使用（三个出口 + 一个特例）

**场景 1 · 人工取用（剪贴板出口）**

```
你:   把 GitHub 的 token 给我
DSH:  [密保卡] 随机抽问 2/3：Q1 你初中母校的名字？ Q2 第一只宠物的名字？
你:   （在 GUI 卡片里作答，答案回传 host 比对哈希）
DSH:  [审批卡] 调取 GitHub token → 出口: 剪贴板   【批准】【拒绝】
你:   （批准）
DSH:  已复制到剪贴板 ✅ 60 秒后自动清除。审计已记录 12:10。
```

**场景 2 · 让 agent 代用（明文永不回显，最常用）**

```
你:   用测试环境的 API key 调一下 X 接口，看能不能通
DSH:  [密保卡 → 审批卡：代用执行 "调用 X 接口"，密钥注入方式 env]
DSH:  调用成功（HTTP 200 · 312ms）。密钥经环境变量注入子进程，全程未回显。
```

**场景 3 · 脱敏核对（masked 出口）**

```
你:   确认一下我存的是不是 ghp_ 开头那个
DSH:  GitHub token：ghp_****c3d4（前3后4）· 2026-12-31 到期
```

**特例 · TOTP 二步验证码**（码 30 秒失效，允许直接回显）

```
你:   GitHub 现在的验证码
DSH:  482 913（剩余 21 秒）
```

**GUI 浏览**：随时打开「保险库」页看全部条目元数据表格（系统/账号/到期/录入时间），可编辑元数据、复制（走剪贴板出口+页内确认）、作废条目。页面上**没有明文也没有密文**。

安全闸门顺序（每次调取都过）：`定位条目 → 密保挑战（限速+5 次锁定）→ 解锁态检查（锁定则 GUI 输主密码）→ DSH 审批卡 → 出口 → 审计日志`。

### 阶段 3 · 多设备与云同步

- **日常**：登记/调取后自动 `sync push`；其他设备 `sync pull`（或开机自动拉取）。云端全程只有 `.age` 密文与版本清单。
- **换新设备 / 新电脑加入**：
  1. 装插件 → `dsh-vault restore`；
  2. 输入主密码 + 提供任一片额外 Shamir 分片（云端片自动拉取，或手抄恢复码）；
  3. 私钥恢复 → 拉全量密文 → 立即可用。**云上没有任何东西需要"解密"，因为云从未见过明文。**
- **换云存储**：改一个端点配置，`sync push` 到新桶即可，旧桶数据作废（反正是密文）。

### 阶段 4 · 生命周期（到期 / 轮换 / 审计）

```
DSH(提醒卡片/IM): 你的「阿里云 AK」还有 7 天到期（2026-12-31）。要现在轮换吗？
你:   轮换
DSH:  已生成新密钥并入库 ✅ 旧版本移入历史（保留 90 天可回滚）。
      新密钥已复制到剪贴板，请到阿里云控制台替换后告诉我"确认"。
你:   确认
DSH:  旧版本已作废。轮换完成，审计已记录。
```

- **每日巡检 job**：到期前 14/7/1 天推送提醒（内容仅元数据）。
- **月度安全报告**（可选）：共 N 条、M 条弱密码、K 组重复使用、J 条将到期——全部脱敏。
- **编码时联动**：agent 在项目里扫到硬编码密钥 → 报告"文件:行号:类型"（不显示完整密钥）→ 建议登记入库并把代码改成 `${ENV_VAR}` 引用。

### 阶段 5 · 异常与应急

| 情况 | 流程 |
|---|---|
| 密保连错 5 次 | vault 锁定 30 分钟 + GUI/IM 告警 + 审计红条 |
| 忘记主密码 | 2 片 Shamir 分片 + 重设流程恢复；若 3 片全失 → 不可恢复（设计如此，需在初始化时明确告知） |
| 私钥文件损坏 | 同上，用分片重建 |
| 设备失窃（锁定态） | 磁盘上只有主密码包裹的私钥 + 密文；可在其他设备改密轮换 |
| 胁迫解锁 | （若启用）输入 duress 暗码答案 → 静默销毁本地私钥与内存密钥，界面只报"挑战失败" |
| 空闲 15 分钟 | 自动锁定，内存密钥清零；下次调取重新 GUI 解锁 |
| 想整体搬家 | `vault backup export`（加密快照）或导出 Bitwarden CSV（明文导出需 GUI 二次确认，会警示） |

## 3. 需要搭建的应用（自研清单）

| # | 组件 | 形态 | 职责 | 阶段 |
|---|---|---|---|---|
| 1 | **dsh-vault CLI**（helper） | 独立可执行程序（Node.js/TS，依赖 age、argon2、剪贴板库） | **全系统唯一接触明文的进程**：加解密、Argon2id、密钥生成、剪贴板写入与定时清除、代用执行（env 注入 + 输出过滤）、Shamir、同步引擎、审计写入 | M1 |
| 2 | **host 插件** | cordis 插件（随 DSH 进程加载） | 向模型注册工具面（`vault_register/list/challenge/get/use/totp/rotate/sync/audit…`）；调用 CLI；管理解锁态；限速与锁定；到期巡检后台 job；与 GUI 的解锁 RPC 通道 | M1 |
| 3 | **skill（SKILL.md）** | markdown 指令 | agent 行为铁律：不复述明文、密钥不进命令行/报告/代码、识别消息中的密钥并建议登记、优先代用出口、IM 来源附警示 | M1 |
| 4 | **client UI 插件** | Web GUI 组件（对齐 dsh-client-ui-* 插件形态） | 解锁对话框（主密码直连 host，不经模型）、保险库浏览页（仅元数据）、到期提醒卡、锁定告警卡 | M2 |
| 5 | **云同步协议模块** | CLI 内置 | sync-manifest 版本向量、last-write-wins 合并、冲突双版本保留 | M2 |
| 6 | （可选）Infisical/OpenBao 后端适配器 | CLI 内置 backend 实现 | 团队共享、动态凭据、租约令牌 | P3 |

## 4. 需要使用的服务（拿来即用，不自建）

| 服务 | 用途 | 候选 | 必需性 |
|---|---|---|---|
| 云 blob 存储 | 存密文、多设备同步 | 对象存储（阿里 OSS / 腾讯 COS / S3 / Cloudflare R2）· WebDAV（坚果云 / Nextcloud）· 私有 git 仓库 | 多设备必需；单设备可缓 |
| 系统剪贴板 | 调取出口 b | pbcopy / wl-copy / Win32（经 CLI） | M1 必需 |
| OS keychain | 私钥文件保护（可选增强） | macOS Keychain / Linux Secret Service / Windows DPAPI | 可选（默认 0600 文件 + 主密码包裹已够用） |
| DSH 既有能力 | 密保问答卡（ask_user_question）、审批卡（ask 策略）、后台 job/goal（巡检）、会话日志（scrub 对象） | 本机 DSH | 直接用 |
| IM 通道适配器 | 登记入口 + 提醒推送 | DSH 生态既有 IM 插件 | 可选 |
| HIBP k-匿名 API | 泄库检查（只上传哈希前 5 位） | api.haveibeenpwned.com | 可选 P3 |
| Infisical / OpenBao | 团队密钥管理后端 | 自托管 | 可选 P3 |

**不需要**：自建服务器、数据库、常驻守护进程、开放任何入站端口。个人场景的全部计算都发生在你的设备上。

## 5. 一天的使用长什么样（串起来）

```
09:00 开机 → DSH 启动 → vault 自动 sync pull（拉昨晚在另一台电脑登记的条目，密文）
09:01 GUI 提醒卡：「阿里云 AK 还有 7 天到期」→ 你点"稍后"
10:30 你对 agent 说："用测试环境 key 调 X 接口" → 密保卡答两题 → 批准 → "调用成功 HTTP 200"
       （密钥全程没出现在对话里）
14:00 你在 IM 里发："记一下新申请的 npm token：npm_xxx" → 回执脱敏 + 日志打码提示
16:20 "把 npm token 给我" → 密保 → 剪贴板 → 去终端粘贴 → 60 秒后剪贴板自动清空
18:00 到期提醒再次出现 → 你说"轮换" → 新密钥生成入剪贴板 → 去控制台替换 → "确认"
       → 每次操作都留下审计日志一行
23:00 sync push → 云端多了几个 .age 密文文件，云端始终不知道里面是什么
```
